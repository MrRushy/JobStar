# JobStar

**Your guide through the job search.**

JobStar is a full-stack job search management and analytics platform designed to help users organize, track, and better understand their job search.

The project is being built alongside my own job search and will evolve based on real problems and workflows I encounter while applying for software development positions.

Rather than remaining a basic job application tracker, the long-term goal is for JobStar to act as a companion throughout the job search by helping manage applications, interviews, resumes, job requirements, and useful search analytics.

## Tech Stack

- React and TypeScript
- Java and Spring Boot
- PostgreSQL and Spring Data JPA
- REST APIs
- Spring Security session authentication

## Current Features

- Private user accounts with registration, login, logout, and session persistence
- Secure password hashing and CSRF-protected requests
- User-owned job applications stored in PostgreSQL
- Create, view, edit, and delete applications
- Application statuses, optional notes, locations, dates, and job-posting links
- Search by company or position
- Status filtering and sorting controls
- A live dashboard with application totals and a status-pipeline breakdown
- Responsive React interface

## Roadmap

JobStar will continue to grow based on real job-search workflows.

Near-term work:

## Project Goals

The main goals of JobStar are to:

- Build a useful application that I can use during my own job search
- Learn modern full-stack development
- Gain experience with React, TypeScript, Spring Boot, PostgreSQL, and REST APIs
- Build and deploy a production-style web application
- Develop the project incrementally based on real usage
- Create a strong full-stack project for my software engineering portfolio
